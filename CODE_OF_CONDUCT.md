# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and focus on the work. Harassment of any kind isn't tolerated.

To report unacceptable behaviour privately, use GitHub's private reporting form:
[open a private report](https://github.com/bishalkarki01/life-admin-mcp/security/advisories/new)
and start the title with **"Conduct:"**. Only the maintainer can see it. Reports are kept
confidential, and you'll get a reply within 7 days. The maintainer may warn, temporarily ban or
permanently ban anyone who breaks this code, following the Contributor Covenant's enforcement guidelines.
