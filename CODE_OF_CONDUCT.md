# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and focus on the work. Harassment of any kind isn't tolerated.

To report unacceptable behaviour, contact the maintainer privately through a
[GitHub security advisory](https://github.com/bishalkarki01/life-admin-mcp/security/advisories/new)
or by direct message to [@bishalkarki01](https://github.com/bishalkarki01).
